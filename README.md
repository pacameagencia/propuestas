# Propuestas

Propuestas de web de Pacame Agencia para concesionarios de coches de alta gama. Cada carpeta es una propuesta para un concesionario, con dos versiones (`a/` y `b/`) y una portada para elegir.

Son demos de diseño: no son las webs oficiales de esos concesionarios y no se indexan en buscadores. Los coches, las fotos y los datos se han sacado de la web pública de cada concesionario.
